# CUDA 전환 후 문제 및 검증 기록

기준일: 2026-10-30. 과거 CPU 실행 기록은 그대로 보존한다.

본문의 `results/` 파일명은 당시 로컬 실행 산출물을 가리킨다. WAV, 보고서, 로그, 패키지 목록은 Git에 포함하지 않으며 검증 수치는 아래에 기록한다.

## 확인한 환경

- 현재 `.venv`: Python 3.12.10, torch 2.4.0+cu121, torchaudio 2.4.0+cu121, CUDA runtime 12.1, funasr 1.4.17.
- 과거 CPU 기록의 Python 3.11.9, funasr 1.4.16과도 다르므로 CUDA 설치만으로 오류가 해결됐다고 단정하지 않는다.
- `torch.cuda.is_available()`는 True, GPU는 NVIDIA GeForce RTX 4070 SUPER.

## 처리 목록

1. [x] Git 정보 없는 배포 폴더에서 WAV 도구가 변환 전에 중단되는 문제 수정.
   - `git rev-parse HEAD` 실패가 보고서 저장용 try 블록 밖에서 발생한다.
   - 커밋은 확인할 수 없으면 null로 기록하고, 실패 이유를 별도로 남긴다.
2. [x] CUDA 환경에서 실제 WAV 변환 재검증.
   - 과거 CPU의 비정상 샘플과 VAD 오류가 GPU에서도 재현되는지는 아직 모른다.
   - 1초부터 시작해 긴 입력으로 확대하고 샘플 수·유한성·처리 시간을 확인한다.
3. [x] README와 계획서의 현재 환경·검증 결과 갱신.
   - CPU 실행 당시 기록과 현재 CUDA 실행 결과를 구분한다.

## 후속 검증

- 실제 GUI 실행 및 기준 음성과 청감 비교.
- 화자 변환, 발화 끝부분 잘림, 실시간 오디오 장치 성능 확인.
- 위 항목은 파일 변환 자동 검사만으로 완료 처리하지 않는다.

## 추가 발견

- [x] VAD 모델이 로컬에 있어도 `fsmn-vad` 별칭 사용 시 원격 revision 조회로 시작이 실패함.
  - 첫 GPU 시도: `results/phase1_cuda_1s.report.json` (모델 서버 이름 조회 실패).
  - 네트워크 허용 재실행: `results/phase1_cuda_1s_online.report.json` (1초 변환 성공).
  - 엔진은 config.yaml/model.pt/am.mvn을 갖춘 로컬 캐시가 있으면 그 경로로 직접 로드하도록 수정. 캐시가 없으면 기존 다운로드 경로 유지.
- 자동 검사 첫 실행은 임시 폴더 접근 권한으로 실패. 제품 오류와 구분하고 접근 가능한 환경에서 재실행한다.

## 최종 검증 결과

- 자동 검사 12개 통과 (`results/cuda_unittest.log`). 추가 검사는 Git 미설치/저장소 없음/타임아웃에도 변환·보고서 저장, VAD 로컬 캐시 선택 및 캐시 미보유 경로를 확인한다.
- 1초 GPU 변환 성공 (`results/phase1_cuda_1s_online.wav`).
- 로컬 VAD 경로 수정 후 네트워크 제한 환경에서 3초·10초·30초·60초 GPU 변환 성공. `HF_HUB_OFFLINE=1`, 기존 모델 캐시 사용, `fp16=False` 유지.
- 저장 WAV를 다시 읽어 전 샘플이 유한하고 무음 전체가 아니며, 입력·출력 샘플 수가 일치함을 확인했다.

| 길이 | 입력/출력 샘플 수 (22,050Hz) | 블록 처리 시간 / 입력 길이 |
|---|---:|---:|
| 1초 | 22,050 | 1.358 |
| 3초 | 66,150 | 0.728 |
| 10초 | 220,500 | 0.569 |
| 30초 | 661,500 | 0.509 |
| 60초 | 1,323,000 | 0.491 |

- 10/30/60초 입력은 `yae_0.wav`를 반복해 만든 60초 시험 파일을 사용했다 (`results/cuda_repeat_60s_input.wav`). 서로 다른 자연 발화 60초를 검증한 것은 아니다. 1/3초는 원본을 잘라 사용했다.
- 수치는 모델 초기화를 제외한 블록 처리 시간 합계 기준이며 첫 블록 비용을 포함한다. 60초 실행의 모델 초기화는 약 13.49초였다. 오디오 장치·네트워크를 포함한 실시간 지연으로 해석하지 않는다.
- 기계 검증 요약: `results/cuda_validation_summary.json`. 최신 패키지 목록: `results/environment-packages-cuda.txt`.
- 과거 CPU의 비정상 샘플/VAD 오류는 위 GPU 검증에서 재현되지 않았다. CPU 원인 자체를 수정·규명한 것은 아니며 Python/FunASR 버전 변화도 있다.
- ffmpeg 미설치 경고는 남아 있지만 이번 WAV 입력·출력은 torchaudio/soundfile 경로로 성공했다. 경고 제거 목적의 패키지 설치는 하지 않았다.
